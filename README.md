# reading-final

Личный репозиторий для самообучения. Здесь лежат учебные планы и материалы по всем темам, которые я изучаю. Со временем будут добавляться новые.

## Что сейчас внутри

**Детская гепатология**
- `Hepatology_Year_Plan.docx` — годовой план: 26 блоков × 14 дней, 28.09.26 – 26.09.27.
- `hepatology/` — уроки в формате `BB-DD_Topic_Name.pptx` (презентация) и `BB-DD_Topic_Name_audio.pdf` (глава для прослушивания). BB — номер блока, DD — номер дня.

**Детская гастроэнтерология**
- `Gastroenterology_Plan_2027-2031.docx` — план после гепатологии: 6 этапов, 98 блоков × 14 дней, 27.09.27 – 29.06.31. Уроки появятся в `gastroenterology/`.

**Anki**
- `anki/` — колода ключевых исследований по детской гепатологии, пополняется ежедневно. Подробности в `anki/README.md`.

**История России**
- `Russian_History_Year_Plan.docx`, `history-russia/` — курс для слушания: главы `BB-DD_Name_audio.pdf`, процедура в `history-russia/PROCEDURE.md`.
