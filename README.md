# reading-final

Daily self-study lessons in pediatric hepatology and pediatric gastroenterology.

- `Hepatology_Year_Plan.docx`: hepatology year plan (26 blocks × 14 days, 28.09.26 – 26.09.27).
- `Gastroenterology_Plan_2027-2031.docx`: sequential GI plan after hepatology — 6 stages, 98 blocks × 14 days, every day detailed (27.09.27 – 29.06.31): upper GI (1–13), small bowel (14–26), IBD (27–52), colon/anorectum/motility (53–65), pancreas and biliary (66–78), intestinal failure, nutrition and transplantation (79–98). GI lessons will go to `gastroenterology/` once the hepatology plan is finished.
- `hepatology/` (and later `gastroenterology/`): lessons named `BB-DD_Topic_Name.pptx` (attending-level deck) and `BB-DD_Topic_Name_audio.pdf` (book-chapter text for a text-to-speech app). BB = block, DD = day.

- `anki/`: Anki deck of landmark and recent studies (pediatric hepatology), grown daily — download `anki/Pediatric_Hepatology_Landmark_Studies.apkg`. See `anki/README.md`.

- `Russian_History_Year_Plan.docx`, `history-russia/`: History of Russia for an interested amateur, in Russian (26 blocks × 14 days, up to 1999). Only listening chapters `BB-DD_Name_audio.pdf` are kept; procedure in `history-russia/PROCEDURE.md`.

A nightly scheduled task adds the next lesson in each track and commits it here.
