# reading-final

Daily self-study lessons in pediatric hepatology and pediatric gastroenterology.

- `Hepatology_Year_Plan.docx`, `Gastroenterology_Year_Plan.docx`: year plans (26 blocks × 14 days).
- `hepatology/`, `gastroenterology/`: lessons named `BB-DD_Topic_Name.pptx` (attending-level deck) and `BB-DD_Topic_Name_audio.pdf` (book-chapter text for a text-to-speech app). BB = block, DD = day.

A nightly scheduled task adds the next lesson in each track and commits it here.
