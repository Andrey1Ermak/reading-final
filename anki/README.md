# Anki — Pediatric Hepatology Landmark Studies

**Get the latest deck:** open `Pediatric_Hepatology_Landmark_Studies.apkg` on GitHub → *Download raw file* → double-click (or Anki → File → Import).
Re-importing updates existing cards and adds new ones; review history is kept (note IDs are fixed per study / per question).

- New cards are added every night (2 recent studies + 6 extra questions on studies already in the deck). See `CHANGELOG.md`.
- In Anki, search `tag:added::2026-11-15` (or `tag:new_study`, `tag:extra_q`) to see what was added.
- Card types: *Named trial → Finding*, *Clinical question → Answer*, *Key number*. Design, result, bottom line and PubMed/DOI links are under "Details" on the back.
- Build: `pip install genanki && python3 build_landmark_deck.py`. Procedure for the daily task: `DAILY.md`.
